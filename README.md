# HEJ MOLD Website

HEJ MOLD 是一個手機優先的靜態網站，用 GitHub Pages 免費部署。網站用來介紹與承接寵物訂製用品。

請先閱讀 [PROJECT_NOTES.md](PROJECT_NOTES.md)，裡面記錄目前設計方向、開發流程、部署方式、使用者偏好，以及換電腦後給 Codex 的交接資訊。

## 主要檔案

- `index.html`: 首頁
- `tag-diy.html`: 吊牌 DIY 產品頁
- `styles.css`: 全站樣式
- `script.js`: 選單互動
- `assets/`: LOGO 與後續產品圖片

## 本機預覽

直接用瀏覽器開啟：

```text
index.html
```

## GitHub Pages

部署設定：

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/(root)`

預期網址：
